# Workspace Guidelines: UI Development

This project does not use Shadcn UI. Do not install, configure, or use Shadcn UI components in this repository.

## UI Style & Components

1. **No Shadcn UI**: Do not use `components.json` or `@/components/ui/` components.
2. **Tailwind CSS**: Use standard Tailwind CSS classes for custom component styling.
3. **Base UI**: For interactive component primitives (e.g., dialogs, dropdowns, popovers), use `@base-ui/react` which is already included in the workspace dependencies.
